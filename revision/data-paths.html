Where the Bytes Go

Five data paths behind the revision cards: sync, stream, batch, fair share across gateways, and inside the model gateway.
Note

Companion to the data-path cards. A queue holds small records. The bytes travel directly when the work starts within a second, and through object storage when the wait is long. Every arrow is numbered in the order things happen.

1. Sync call: the queue lives inside the gateway

2. Stream: frames pushed straight to the pinned host

3. Batch job: object storage and Kafka, because the wait is long
